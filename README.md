# EasyBosh V2 🎓

Application mobile éducative pour les élèves en classe d'examen au Cameroun.

## 🚀 Fonctionnalités

### 👨‍🎓 Pour les Étudiants
- 📚 Bibliothèque de cours par matière
- 🧩 Quiz interactifs avec corrections
- 📊 Suivi de progression personnalisé
- 📝 Préparation aux examens officiels

### 👨‍🏫 Pour les Enseignants
- 📖 Gestion et création de contenu
- 👥 Suivi des performances élèves
- 📈 Analytics détaillées

### 👨‍💼 Pour les Administrateurs
- 🏢 Gestion institutionnelle
- 📊 Tableaux de bord globaux
- 🔐 Contrôle d'accès complet

## 🏗️ Tech Stack

- **Frontend**: Flutter/Dart
- **Backend**: Supabase
- **State Management**: Riverpod
- **Navigation**: GoRouter
- **Charts**: FL Chart
